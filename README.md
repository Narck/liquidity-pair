# Liquidity Pair

The official landing page for Liquidity Pair (LP), paired with Meteora's MET token on Solana.

## Development

```bash
npm install
npm run dev
```

The local site is available at `http://localhost:5173`.

## Production build

```bash
npm run build
```

## Deployment

Pushes to the `main` branch are built and deployed automatically through GitHub Pages.
